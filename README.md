# Thinking-DeFi

### Summary

In modern smart contract audits, obvious coding patterns and basic vulnerabilities — such as access control issues, reentrancy, and similar classes of bugs — can already be identified directly with AI. As auditors, the greater focus should therefore be on discovering vulnerabilities that are tightly coupled to business logic.
